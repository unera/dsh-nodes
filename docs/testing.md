# Что тестируется без человека, а что только с ним

Файл для нас двоих: чтобы не выдумывать заново, кто что может проверить.

## Могу сам (сервер + мой узел на этой же машине)

| сценарий | чем |
|---|---|
| отказ песочницы, классификация, коды возврата | `nodes_call` на узел `ai.uvw.ru` |
| режимы `ro`/`rw`/`full` и потолок узла | тот же узел, аргумент `sandbox` |
| `session.chdir`/`mkdir`/`cwd`, границы `roots` | `nodes_call` на api `session` |
| очередь: курсор, epoch, повторная доставка, таймауты | автотесты `test/queue*`, `test/e2e` |
| миграции `state.sqlite`, `credentials.yaml`, `config.json` | автотесты клиента |
| админ-API: узлы, алиасы, заявки, отзыв токена | автотесты `test/e2e`, `test/ws` |
| регрессия схем сервисов cordis (`inject`) | `test/policy.test.mjs` |

## Нужен ты

| что | почему не могу |
|---|---|
| клик «Allow once» / «Reject» в диалоге апрува | окно живёт в GUI, у меня только API |
| переключение пресета сессии (`Full access` / `read-only`) | это твой выбор, не мой |
| установка клиента (`npm install -g unera/dsh-node-client`) | обновление лежит вне песочницы узла |
| смена конфига узла (`dshnc policy`, `dshnc workdir`) | политику владельца не должен менять агент |
| взгляд на GUI: админка, панель «Узлы», диалог апрува | я не вижу браузер |
| обрыв на полпути: выключить ноутбук во время команды | нужно физическое действие |
| два клиента с одним токеном (двойное исполнение) | нужна вторая машина или копия состояния |
| машина без `bwrap` (userns запрещён) | нужен другой хост |
| необычная локаль (не ru/en) или ФС без прав | нужен другой хост |

## Как это выглядит на практике

1. Я говорю, что именно проверяю и какой результат жду.
2. Ты делаешь своё действие (клик, переключение, установка) и пишешь «готово».
3. Я прогоняю вызов и показываю **факт из журнала или ответа узла**, а не пересказ.
4. Если что-то не сходится — ищем причину, а не подгоняем объяснение.

## Чего не делаю без спроса

- не меняю политику твоего узла (`max`, `ask`, `roots`) ради удобства проверки;
- не прошу ставить клиент с моих ссылок — только из репозитория;
- не запускаю на твоей машине ничего разрушительного «для теста».

## Спека клиентского протокола

`spec/openapi.yaml` (английский, публичный) описывает только то, что нужно новому
клиенту: регистрацию, объявление API, присутствие, выдачу команд и результаты.
Админского API там нет намеренно. Русский перевод — `docs/openapi.ru.yaml`;
если правишь смысл, правь оба.

Проверить, что файл разбирается и не содержит битых ссылок:

```sh
npx --yes js-yaml@4 spec/openapi.yaml > /tmp/spec.json
node -e 'const d=require("/tmp/spec.json"); console.log(d.openapi, Object.keys(d.paths).length)'
```
